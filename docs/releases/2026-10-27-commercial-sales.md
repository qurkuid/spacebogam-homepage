# 상업광고 상담 영업 랜딩 — 2026-10-27

메타 소재 4종과 광고 ID 7개에 맞춰 카페·매장/사무실의 메시지, 공간 예시, 확인 항목을 보여준다. 1차 버튼은 `/consultation/?type=commercial&vertical=shop|office`로 연결하며 광고 정보를 유지한다. 이미지 8장은 AI 생성 공간 예시로 표시한다. 업종별로 히어로 1장과 상세 3장만 로딩한다.

상담은 최신 운영본의 순차 질문을 유지한다. 상업 광고 유입은 성함 질문부터 시작하며 업종이 미리 선택된다. 재시작도 광고 업종을 유지한다. 주거 상담, 카카오 정보 채우기, 필수 동의, 개인정보 연락처 매칭 비활성, 중복/테스트 접수 전환 제외를 보존한다.

## 검증

- 관련 자동 검사 39개 통과: 상업 소재/전화 중복/상담 진입/카카오/자산 버전.
- Chrome for Testing: 광고 4종 × 360/390/1440px의 이미지·CTA·가로 넘침 검사 12개 통과.
- 카페·매장 390px와 사무실 1440px에서 전체 질문·동의·모의 제출 완료. 실제 접수 및 고객 알림 전송 없음.
- 기존 `consultation-disclosure`의 옛 카카오 별도 4항목 폼 기대값은 현재 main의 정보 채우기 방식과 맞지 않아 실패한다. 이번 변경과 무관하며 별도 기록했다. 전체 테스트 통과로 보고하지 않는다.
- 이전 20개 페르소나 평가는 AI 시뮬레이션이며 실제 고객 실험이나 전환율 검증이 아니다.

## 배포 범위

실제 서비스 프로세스가 읽는 최신 운영 릴리스를 복제하고 랜딩 3파일, JPEG 8장, 상담 HTML/JS 3파일만 덮어쓴다. 문서, 테스트, 분석 보고서, 원본 PNG, 다른 작업 중인 파일은 공개 릴리스에 추가하지 않는다. 변경 파일은 해시와 origin 응답 바이트로 검증하고 나머지 파일이 보존되는지 검사한다. 광고 예산·광고 목적지 설정은 변경하지 않는다.

Git 기준보다 최신 운영본에 있던 동의 제거와 전환 중복 방지 변경도 상담 파일에 보존했다. 원래 작업 디렉터리의 미완성 주거 묶음 폼은 포함하지 않았다.
