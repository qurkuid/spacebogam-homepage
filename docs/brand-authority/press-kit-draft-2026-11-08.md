# 공간보감 인테리어 — 편집자·기자용 취재 자료 초안
작성: 2026-11-08 · 상태: **비공개 작업 초안 / 외부 발송 및 공개 게재 전 승인 필요**

> 목적: 광고 문구가 아니라, 독립적인 편집자가 확인 가능한 현장 자료와 전문가 해설을 전달한다. 모든 설명은 공개된 공간보감 자사 자료에서 확인한 주장이다. 독립 검증이나 제3자 평가와 혼동하지 않는다.

## 1. 기본 회사 정보 — 공개 근거
- 브랜드/상호: 공간보감 / 공간보감 인테리어 디자인
- 전문 분야: 부산 아파트 인테리어·리모델링, 구축 아파트 실측·설계·견적·시공
- 공식 사이트: https://spacebogam.kr/
- 회사 소개: https://spacebogam.kr/overview.html
- 작업 과정: https://spacebogam.kr/process.html
- 포트폴리오: https://spacebogam.kr/portfolio.html
- 사업자등록번호/실내건축공사업 등록번호 및 주소·전화: 사이트 하단 회사 정보에 기재되어 있으며 외부 소개 시 최신 상태를 다시 검증할 것
- 담당자 인터뷰·사진 사용 및 시공 기록의 사실 확인: 공간보감 측 사전 승인 필요

### 전문적 포지셔닝 (제안 표현)
부산의 구축 아파트에서 **생활 동선과 기존 구조의 제약을 함께 고려해 설계 결정을 기록하는 인테리어 스튜디오**. 평면·수납·공조·현관 동선 등 실제 문제를 어떻게 풀었는지 프로젝트별로 설명하는 것이 강점이다.

이 문구는 브랜드 관점의 제안이며, 업계 전체 대비 우수성·전문가 선정·최고 등급을 의미하지 않는다.

## 2. 인용 가능한 공개 프로젝트 팩트시트

### A. 반여동 메가센텀 한화꿈에그린 49평 — TV 없는 가족 거실
- 공개 프로젝트: https://spacebogam.kr/case-mega-centum-49py.html
- 현장 위치 수준: 부산 해운대구 반여동, 49평 (동·호수 사용 금지)
- 공개 설계: TV 없는 거실과 주방의 개방감, 빌트인 수납, 현관 벤치·붙박이장·포켓 중문
- 해당 사례 한정 공개 공사 범위: 창호 포함, 시스템에어컨 4대 포함, 확장 6개 포함
- 해당 사례의 공개 금액대: 1억 원 이상 (다른 현장 견적 기준으로 일반화 금지)
- 사이트에는 완공 사진 76장과 설계 이야기 링크가 연결되어 있다.
- 기고 주제: '부산 40~50평 구축 아파트에서 공사비를 비교할 때 왜 창호·확장·공조 범위를 따로 봐야 하는가'
- 사진 사용권·견적 범위 확인: 편집 전 담당자 재확인 필요

### B. 동래 사직쌍용예가 1차 42평 — 다섯 식구의 기둥·수납 통합
- 공개 프로젝트: https://spacebogam.kr/case-sajik-ssangyong.html
- 현장: 부산 동래구 사직동, 42평
- 공개 설계: 철거 불가 기둥을 우드 수납과 연결, 로봇청소기 공간 마련, 유리 중문으로 현관 시야 확보
- 해당 현장 공개 기록: 상담 20시간 이상, 시공 약 7주. 절대 다른 프로젝트의 표준 소요일로 표현하지 말 것.
- 기고 주제: '철거할 수 없는 기둥을 단점이 아니라 가족 수납 계획의 축으로 활용한 방법'
- 독자에게 가치 있는 질문: 기둥의 위치가 수납 배치·놀이·시야에 주는 영향을 어떻게 검토했는가?
- 확인 필요: 도면 공개/고객 정보 비식별, 현장 담당자 설명, 사진 사용 허가

### C. 금정구 구서동 쌍용스윗닷홈 50평 — 반려견과 동선
- 공개 프로젝트: https://spacebogam.kr/case-guseo-ssangyong-sweetdot-home.html
- 현장: 부산 금정구 구서동, 50평
- 공개 설계: 중문을 거실 쪽으로 이동해 욕실을 중문 밖 현관 영역에 배치; 산책 후 씻고 거실로 들어오는 흐름
- 사이트 공개 사진: 162장
- 기고 주제: '반려견의 산책 후 관리 동선이 중문과 욕실 배치를 바꾼 이유'
- 고객·반려동물 개인정보, 실제 사용자 만족도·장기 성능은 확인되지 않았으므로 주장하지 말 것.

### D. 사직쌍용예가 1차 32평 — 대면형 주방과 공조
- 공개 프로젝트: https://spacebogam.kr/case-sajik-32py.html
- 현장: 부산 동래구 사직동, 32평
- 공개 설계: 대면형 주방·수납, 시스템에어컨 포함
- **금액, 샤시·확장 포함 여부는 미공개/문의로 기재됨. 추정 금지**
- 기고 주제: '오래된 아파트에서 주방 배치·공조를 함께 검토할 때 확인해야 할 제약'

## 3. 매체별 제안 초안 (발송 전 편집/허가 필수)

### 오늘의집 — 전문가집들이/노하우
- 실제 공개 분류: https://ohou.se/frequentlyAskedQuestions 에서 전문가집들이(인테리어 전문가가 시공 후 작성한 포트폴리오), 노하우(인테리어 가이드)를 소개.
- 제안: '반려견 산책 후 욕실 동선을 해결한 부산 50평 실거주 설계' 프로젝트를 사진+배치 결정+인테리어 팁 형태로 제출 검토.
- 확인 필요: 업체/작가 신청 절차, 이미지 라이선스, 포트폴리오 게재 자격, 광고 표시.

**제안 소개문 초안**:
“반려동물과 사는 집에서 중요한 것은 마감재뿐 아니라 집에 들어오는 첫 10초의 동선일 수 있습니다. 부산 구서동 50평대 프로젝트에서 공간보감은 중문과 욕실의 상대적 위치를 조정해 산책 후 발을 씻고 생활 공간으로 들어가도록 현관 동선을 정리했습니다. 실제 완공 사진, 설계 과정, 주의점 중심으로 사례를 공유하고자 합니다.”

### 브리크매거진 등 건축·공간 편집 매체
- 참고 매체: https://magazine.brique.co/ — 실제 공간 프로젝트 사례를 보도하는 편집 매체임.
- 제안: '철거 불가 기둥을 수납 구조로 전환한 사직 42평' 사례를 **공간 문제 / 제약 / 도면 / 선택 이유 / 결과 사진**의 5장 구조로 정리.
- 확인 필요: 공식 프로젝트 접수·제보 채널, 미디어킷 규격, 저작권, 취재 방식. 확인되기 전 발송·게재 보장 금지.

**제안 소개문 초안**:
“기둥을 없앨 수 없는 아파트에서 동선을 정리하는 설계는 어떤 방식으로 진행될까요? 공간보감은 부산 사직동 42평 아파트에서 철거가 불가능한 기둥을 수납장과 통합하고, 다섯 식구의 생활 동선을 기준으로 거실·현관의 시야와 수납을 구성했습니다. 시공 결과뿐 아니라 설계에서 내려진 선택과 현장 조건을 설명하는 프로젝트 자료를 제공할 수 있습니다.”

### 자재 브랜드 시공사례 코너
- 후보: 창호·바닥재·욕실·조명 등 실제 납품 확인이 가능한 제조사/유통사 공식 채널.
- 사전 조건: 정확한 브랜드·모델·시공범위·사용 사진 확인. 단지 취향/사진과 유사하다는 이유로 특정 브랜드 시공 주장 금지.
- 첫 과제: 공개 현장 자료에 실제 제품명 및 사용 허가가 있는 프로젝트 2개 조사 후 매체를 선정.

## 4. 편집자가 인용할 수 있게 하는 요약 형식
각 대표 사례에 다음 7개 항목을 함께 제공한다.
1. 문제: 기존 생활/구조의 구체적인 제약
2. 검토: 실제 현장측정·가능/불가 조건
3. 선택: 수납·동선·공조·마감 결정의 이유
4. 범위: 포함/제외 공정, 금액을 공개할 경우 현장 한정 표기
5. 근거: 전후 사진·도면·설계 기록의 별도 URL
6. 한계: 장기성능/만족도 등 측정하지 않은 사실 분리
7. 저작권: 사진·도면·고객 사례 외부 활용 동의 상태

## 5. 실제 배포 전 필수 승인
- [ ] 대표/담당자의 시공 사실 및 회사 정보 확인
- [ ] 사진과 도면의 외부 게재 허가 확인 (고객·촬영자·디자이너)
- [ ] 도면에서 개인 식별·동호수 및 민감 정보 제거
- [ ] 원고가 광고성 홍보임을 숨기지 않음; 매체의 편집 판단과 유료광고를 구분
- [ ] 기사 초안을 외부에 보내기 전 승인
- [ ] 공개 사이트 자료 추가·수정은 기존 배포 승인 게이트 통과

## 6. 성과 측정
- 외부 게재 URL (독립 편집 검수 / 자체 발행 / 유료 광고 구분)
- 게재물에 회사명과 원문 프로젝트 URL이 표시되는지
- AI 답변 실제 출처 링크에 프로젝트 URL이 나타났는지
- GA4 유입 및 상담과 분리 측정. 인용=클릭=상담으로 혼동 금지.
