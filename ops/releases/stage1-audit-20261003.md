# 공간보감 홈페이지 기술 감사 1단계 수정

기준 source main: 675a49bb5f157ae6e04d3e37c0a4175bf5a851b4. 운영 기본 릴리스: releases/entry-675a49bb5f15.

운영에는 main 외의 기존 사진과 콘텐츠가 있으므로 전체 Git archive 배포를 하지 않는다. 현재 운영 릴리스를 복사하고 동봉 patch 또는 manifest의 195개 파일만 적용한다. 각 before_sha256이 일치하고 신규 파일이 없어야 적용할 수 있으며, 모든 after_sha256을 확인한다. 나머지 전체 파일의 바이트를 이전 릴리스와 비교한 뒤 current 링크를 원자적으로 전환한다. 로컬 정적 HTTP 검사 실패 시 이전 링크로 복구한다. 공개 HTTPS의 별칭 리다이렉트는 실제 최종 주소의 파일을 비교한다.

변경: 없는 홈 앵커를 제공 중인 안내 페이지로 연결, 인사이트 분류/해시/키보드 동작, 가이드 모바일 버튼 간격, 공통 메뉴, 사직 사례 지역 분류, 제작용 표현과 상업 상담 안내 정리. 사진이 없는 상업 페이지를 실제 시공 포트폴리오로 소개하지 않는다. 상업 상담은 사무실 방문이 기본이고 전화는 방문 일정 확인으로 안내한다. 표시번호 1551-0163과 발신 추적번호 050713881252는 유지한다.

현재 신청 초안은 같은 탭 sessionStorage에 보관한다. 2시간 이상 지난 초안, 명시적 재시작, 접수 성공 시 삭제한다. 파일 바이너리는 보관하지 않으며, 업로드가 끝나지 않은 파일은 다시 선택하도록 한다. 제출 결과가 불확실한 경우 기존 payload와 event ID를 보존하고 편집을 막아 같은 요청만 재확인한다. 선택한 아파트 동은 상세주소에 먼저 입력한다. 입력 3개와 공간 유형/동의 선택 안내를 명확히 한다.

검증: 변경 관련 Node 모델 17/17 통과. 모든 외부 요청을 가로챈 Chromium 23개 주요 페이지의 상호작용 25/25, 추가 주소/히스토리/별칭 6/6, 초안 복원/만료/오류/저장 차단/필터/메뉴 19/19 통과. 기존 공개 경로에서 앵커 링크 180개 재검사, 없는 앵커 0. 변경 HTML 190개에서 사진 참조와 tel/sms 대상 동일. 공통 추적 자산과 질문 원본 동일. 감사 당시 140개 경로 desktop/mobile 렌더 앱 JS 예외 0.

전체 기존 테스트는 감사 기준 160개 중 119 통과/41 실패였다. 구 DOM/문구 기대값, VM 모의 환경, 경로 검사 등의 실패와 전역 캐시 검사 229개/홈 baseline 실패는 2단계에 남긴다. 이 릴리스의 기능 검사를 전체 CI 통과로 표현하지 않는다. 저장소에는 일반 테스트 workflow가 없고 GitHub Pages build workflow만 있다.

실고객 신청, DB 조회/저장, 전화·SMS·카카오·알림, 실제 광고 전환 발송, 광고 설정/재개, 운영 보안 설정 변경은 하지 않는다. 백엔드 ingest와 실SDK 전달, 모바일 Safari/실기기 캐시 상태는 미검증이다.
