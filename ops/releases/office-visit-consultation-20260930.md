# 사무실 방문 상담 문구 배포

운영 기본 릴리스: `releases/consult-construction-date-20260930-ad81b5f7`.

원격 main과 운영 페이지에는 이미 별도 배포된 콘텐츠 차이가 있습니다. 이 커밋의 일반 파일 변경은 main의 상담 문구만 수정합니다. 운영에는 현재 릴리스를 복사한 뒤 이 디렉토리의 patch를 적용하여 기존 이미지·콘텐츠와 미배포 사용자 변경을 보존합니다. FAQ 원본 `data/faq.json`은 운영에만 존재하므로 patch에만 포함합니다.

배포 전 모든 대상의 SHA-256이 JSON manifest의 `before_sha256`과 일치해야 합니다. `patch --dry-run -p1` 성공 후 새 릴리스에 적용하고 `after_sha256`을 검증합니다. `current` 심볼릭 링크 전환 뒤 로컬 HTTP와 공개 HTTPS의 모든 대상 파일 SHA-256을 다시 비교합니다. 파일이나 활성 릴리스가 달라졌다면 배포를 중단합니다.

기존 비용·소요시간·보장, 질문 ID·필수 여부·시공 희망일·날짜 제약, API payload와 광고 추적 속성은 유지합니다. 상담 신청 접수는 방문 예약 확정과 구분합니다. 실제 고객 문의를 테스트 제출하지 않습니다.
