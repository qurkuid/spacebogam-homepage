마이 공간보감 회원가입

공간보감 고객 전용 앱에 가입하고, 본인에게 연결된 프로젝트·견적·일정·현장 사진을 확인하고 문의를 남길 수 있습니다. 가입과 로그인은 앱에서 진행합니다.

회원가입은 상담 신청과 별개입니다. 상담을 신청하거나 공사 계약을 하지 않아도 고객계정을 만들 수 있으며, 회원가입만으로 상담이 접수되거나 방문이 예약되지 않습니다.

앱에서 회원가입하기

  1. 1. 마이 공간보감 앱 설치아래 Android 설치 파일을 내려받아 앱을 실행합니다. 현재 앱은 출시 준비 중이며 iPhone 설치는 아직 제공하지 않습니다.
  2. 2. 로그인 화면 → 카카오로 회원가입처음 이용한다면 회원가입 화면에서 제공 정보와 이용 조건을 확인합니다. 기존 회원은 카카오 로그인 또는 기존 계정 로그인을 이용합니다.
  3. 3. 카카오 인증 및 동의회원가입 화면의 공식 카카오 로그인 버튼을 누릅니다. 카카오 연결 과정에서 필수 고객계정 약관과 만 14세 이상 이용 조건을 확인하고 동의합니다. 이름·전화번호 제공 기능이 준비되면 두 항목은 선택 동의로 표시되며, 제공하지 않아도 가입할 수 있습니다. 이 페이지에는 별도 동의창이나 체크박스가 없습니다.
  4. 4. 고객계정 생성 및 앱 이용처음 인증하면 INTM에 고객계정을 만들고 앱으로 돌아갑니다. 이미 가입한 카카오 계정이면 같은 고객계정으로 로그인합니다. 신규 회원은 기본 이름으로도 가입할 수 있고 별도의 연락처 입력을 가입 조건으로 요구하지 않습니다.
Android 앱 설치 파일 받기

Android 설치용 사전 배포본입니다. 앱스토어·Google Play 정식 출시 또는 실제 기기 검증 완료를 뜻하지 않습니다.

가입 시 제공 정보와 수집 조건

정보조건이용 목적
카카오 회원 식별자카카오 가입·로그인 시 필수고객 회원가입, 재로그인과 회사별 고객계정 연결
이름선택 · 제공 기능 준비 중승인 후 제공에 동의한 신규 회원의 회원프로필 등록·관리, 상담 입력란 자동 입력
전화번호선택 · 제공 기능 준비 중승인 후 제공에 동의한 신규 회원의 회원프로필 등록·관리, 상담 입력란 자동 입력

상담 신청 시에는 자동 입력된 값을 본인이 확인·수정한 뒤 접수합니다. 이름·전화번호를 제공하지 않은 회원도 직접 입력하여 상담을 신청할 수 있습니다.

이름과 전화번호를 제공하지 않아도 회원가입·로그인이 가능합니다. 고객 경로에서는 카카오 이메일·닉네임을 조회하거나 회원정보로 저장하지 않습니다. 공통 카카오 연결 화면에 이메일 동의 항목이 표시될 수 있으나 고객 매칭에 사용하지 않습니다.

카카오 회원 식별자와 신규 회원이 선택 제공한 회원프로필은 회원 탈퇴 또는 이용계약 종료 시까지 처리하며 탈퇴 시 삭제·익명화합니다. 법령상 보관 대상과 인증·연결 해제 기록의 정리 시점은 개인정보처리방침에서 확인할 수 있습니다.

가입 후 계속 이용하는 고객 서비스

  • 본인에게 연결된 프로젝트, 견적, 일정과 현장 사진 확인
  • 본인 프로젝트에 대한 문의와 요청 등록·확인
  • 고객계정 관리, 로그인 연결과 회원 탈퇴

가입 직후 연결된 프로젝트가 없다면 해당 정보는 비어 있을 수 있습니다. 회사가 본인과 자료의 관계를 확인해 연결한 정보만 볼 수 있습니다. 이름·전화번호·이메일이 같다는 이유로 기존 고객이나 프로젝트를 자동으로 합치지 않습니다.

기존 고객은 기존 계정으로 로그인한 뒤 내 정보에서 카카오 계정을 연결해 주세요.

회원 탈퇴

앱의 메뉴 → 계정 삭제 → 계정 탈퇴에서 탈퇴할 수 있습니다. 카카오로 처음 가입한 비밀번호 없는 계정은 비밀번호를 비워 두고 현재 로그인으로 본인 확인을 진행합니다. 탈퇴 시 고객 로그인 연결과 세션을 종료하고 회원프로필을 삭제·익명화합니다.

사진·문의 등 등록 데이터의 통합 삭제와 법령상 별도 보관 항목은 계정 삭제 안내를 확인해 주세요.
