간단 로그인

정적 사이트라 서버에 바로 저장하지 않습니다. 여기서 사례를 작성·수정한 뒤 cases.json을 내려받아 개발팀장에게 전달하면 사이트에 반영됩니다(직접 실행 가능하면 아래 발행 방법 참고).

초기값(로컬 확인용): ggbg-case

사진 파일은 이 화면에서 올리지 않습니다. 아래 이미지 규격을 지켜 파일을 준비한 뒤, assets/case/<슬러그>/ 폴더에 넣고 경로를 입력하세요.

비우면 제목에서 자동 생성

'허가'가 아니면 절대 게시되지 않습니다.

이미지 규격 — 형식 JPEG/WebP, 파일명은 영문 소문자·하이픈만(예: living-after.jpg), 색공간 sRGB.
썸네일: 4:5 세로, 가로 800px 이상, 500KB 이하. 현장 사진: 4:3, 가로 1200px 이상, 1.2MB 이하.
alt 텍스트 형식: "[공간유형] [프로젝트명] [시공 전/후] 사진" — 얼굴·로고 등 식별정보 제외.

사례 1건 발행하는 방법 (개발 도움 없이)

  1. 위에서 "새 사례"로 항목을 만들고 모든 필수 항목을 채웁니다.
  2. 이미지 규격에 맞춘 사진 파일을 assets/case/<슬러그>/ 폴더에 넣습니다.
  3. 사진 사용 허가가 '허가'인지, 아래 체크리스트가 모두 초록색인지 확인합니다.
  4. 발행 상태를 '발행'으로 바꾸고 저장합니다.
  5. "cases.json 다운로드"로 파일을 받아 data/cases/cases.json에 덮어씁니다.
  6. 터미널에서 python3 scripts_build_case.py 를 실행하면 사례 페이지와 포트폴리오 목록이 자동으로 만들어집니다.
  7. 로컬에서 결과 페이지를 확인한 뒤, 개발팀장에게 배포를 요청합니다 (실서비스 배포는 별도 승인 절차).
