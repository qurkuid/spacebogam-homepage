# CMP-252 상담 폼 제출 이탈 조사

관찰 시각: 2026-07-31 09:10 KST  
운영 자산: `assets/consultation-form.js?v=194d5f7c` (`publish/main`과 SHA-256 일치)

## 1. 배경

2026-07-25 수집 시작 후 상담 CTA보다 폼 시작이 많고, 실제 제출이 거의 없어
계측 중복 또는 제출 차단을 먼저 확인했다. 광고·예산·가격은 변경하지 않았다.

## 2. 관찰

### 계측 정합성

- 최신 28일 집계: 방문 400, 10초 이상 참여 154, CTA 23, 폼 시작 35, 제출 0.
- 현재 집계 계약은 `form_start`를 **독립 진입점**으로 표시한다. `/consultation/apply/`
  직접 링크와 안내 페이지를 거친 진입이 모두 가능하므로 CTA 23 < 폼 시작 35는 현재
  모델에서 단조성 위반이 아니다.
- 품질 상태는 `ready`, 표본 세션 400, `isMonotonic=true`, 경고 0건이다.
- 과거 `invalid_sequence` 경고는 모든 폼 시작이 CTA 뒤에 온다고 가정한 집계 모델의
  문제였고, 현재 수치만으로 중복 발화를 입증할 수 없다.

### 실제 제출

iPhone 390×844 뷰포트와 Instagram 인앱 브라우저 UA로 운영 여정을
홈 → 상담 안내 → 상담 신청서 순서로 통과했다.

- 질문 API: HTTP 200, 전체 28개 / 필수 11개.
- 제출 preflight: HTTP 204, `Access-Control-Allow-Origin: https://spacebogam.kr`.
- 빈 제출: 첫 누락 필드인 성함으로 포커스가 이동하고
  `「성함을 알려주세요.」 항목을 입력해주세요.`가 폼 하단에 표시됨.
- QA 표식(`is_test=1`)과 비식별 테스트 값으로 실제 제출: HTTP 201.
- 성공 화면 표시, 콘솔 오류 0건.
- 이벤트: `lead_form_view → lead_form_start → lead_submit_success`, 모두 `isTest=true`.

따라서 버튼·CORS·서버 저장의 하드 차단은 재현되지 않았다. 다만 사용자는 제출 버튼
근처의 하단 오류를 본 직후 첫 필드로 스크롤되는데, 첫 필드에는 오류 표시가 없어
모바일 화면에서 실패 이유가 사라진 것처럼 보인다. 또한 어느 필드까지 작성했는지
알 수 있는 계측이 없었다.

## 3. 수정

- 첫 누락 필드 바로 아래에 `필수 입력 항목입니다.`를 표시한다.
- 오류 필드에 `aria-invalid`/`aria-describedby`를 연결해 스크린리더와 키보드
  사용자도 원인을 확인할 수 있게 했다.
- GA4에 다음 개인정보 비수집 이벤트를 추가했다.
  - `lead_form_field_complete`: 질문 ID, 타입, 순서, 필수 여부만 기록
  - `lead_form_validation_error`: 첫 누락 질문 메타데이터만 기록
  - `lead_form_abandon`: 완료 필드 수, 마지막 질문 ID, 필수 필드 수만 기록
- 이름·전화·주소·답변 값과 질문 문구는 분석 이벤트에 보내지 않는다.
- `consultation-form.js`도 내용 해시 캐시 버스팅 대상에 포함해 Meta 인앱 브라우저가
  구버전 자산을 계속 쓰는 것을 막았다.
- 운영 재현 프로브 `scripts/qa/cmp252-consultation-submit-probe.mjs`를 남겼다.

## 4. 검증

- 상담 폼/귀속 회귀 테스트 23개 통과.
- 신규 검증:
  - 빈 제출 시 인라인 오류와 접근성 속성 생성
  - 필드 완료 이벤트 중복 방지
  - 답변 값이 분석 이벤트에 포함되지 않음
  - 이탈 이벤트가 마지막 완료 질문과 완료 개수만 기록
- `node --check` 2개 통과.
- `git diff --check` 통과.
- 자산 버전 스탬프 검사 통과: `consultation-form.js=1c5a13a2`.

## 5. 남은 위험과 결재

- 실제 스마트폰이 아닌 Chrome의 iPhone/Instagram UA·뷰포트 재현이다. 운영 배포 전
  QA·버그 트리아지 엔지니어가 실제 iOS/Android와 Meta 인앱 브라우저에서 독립 검증해야 한다.
- 필수 11개 자체가 높은 마찰일 가능성은 크지만, 필드별 실측 전에는 필수 항목을 줄이지 않는다.
- 배포 후 최소 7일 또는 폼 시작 30세션까지 필드 완료/이탈 이벤트를 읽어 첫 병목 필드를
  확정한 뒤, 별도 승인으로 최소수집 개편을 결정한다.
- 운영 배포는 전략·성과 책임자 결재 전 수행하지 않는다.
