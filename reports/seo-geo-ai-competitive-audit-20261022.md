## 현재 검수에서 확인한 사실
- 프로젝트 13개, 홈페이지 표시 완성 사진 642장. 프로젝트마다 심층 설계 저널 및 출처 구분(블로그 연계 9개, 사진 근거 4개).
- 기존 홈 캐러셀은 화면 6건 vs JSON-LD 4건으로 불일치 → 이번 브랜치에서 6건으로 정정.
- 4개 사례 페이지에 BreadcrumbList 누락 → 이번 브랜치에서 3단계 정본 경로 추가.
- 화명 코오롱하늘채 사례에 OG 대표이미지 누락 → 실파일 연결.
- 홈페이지의 1,047장 문구와 포트폴리오의 642장 표시 불일치 → 같은 기준으로 통일.
- 홈페이지와 13개 사례의 sitemap lastmod가 실제 최근 수정 시점을 반영하지 않음 → 2026-10-22로 갱신.
- 다수의 완료 사진 alt가 '완성 공간 123' 형태로 일반적이다. 파일명·사진 번호만으로 공간 유형을 추측하면 안 되므로 개별 이미지 맥락 검수 전까지 자동으로 '주방/현관'을 단정하지 않음.
- 디자인해랑 사이트의 사례에서는 평형·공사 기간·자재·공간별 구체 정보 등 확인하기 좋은 구성. 공간보감도 실제 DB에서 검증 가능한 연도·기간·자재 등 누락 필드를 보강해야 한다.
- 홈페이지/일부 상세 페이지의 전화 표시와 `tel:` 목적지 불일치 가능성이 발견됨. 실제 사용 전화번호와 전환계측을 확인하고 수정해야 하므로 이번 변경에는 포함하지 않음.
- 내부 SEO 회귀 테스트 `tests/seo-content.test.js` 는 캐러셀의 6개를 일치시키는 주요 검사이며, `tests/seo_baseline.py` 는 기존 URL, canonical, 구조화 정보, 분석 마커 손실을 검사한다.

## 검증되지 않은 항목 — 이 부분을 제외하고 95점 이상 달성 주장 금지
1. 실제 Google Search Console/네이버 서치어드바이저의 색인율과 노출/클릭수 및 유입 키워드
2. 현장별 사진 다수의 자세한 alt·캡션과 고유성, 원본 출처의 사진 단위 검수
3. 모바일 Core Web Vitals(LCP/INP/CLS) 실측, 페이지 레이아웃 스냅샷
4. Naver/Google 지도, 오늘의집, Linktree 등의 주소·대표 전화·업체 정보 정합성
5. 동일 조건의 경쟁사/공간보감 AI 검색 실제 추천 실험 및 비브랜드 검색어 SOV
