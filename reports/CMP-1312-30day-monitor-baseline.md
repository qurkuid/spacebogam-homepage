## 4. 열린 리스크 2건

### R1. 업종 라우팅 결함 — 표시 불일치 (미해소, 범위 정정)

라이브 JS는 `cmp1312-face-v4`이며 `assets/commercial-call.js:156`의 `content.split('__')[0]` 때문에 `utm_content=shop_a` / `shop_b` 를 업종으로 해석하지 못하고 **기본값 `office` 문구를 렌더**한다. 배포된 파일을 직접 받아 해당 라인을 재확인했다 (2026-08-23 09:00 KST).

**정정 — 집계는 오염되지 않았다.** 이전 기재("매장 클릭이 전부 office로 집계")는 틀렸다. CMP-1336이 신설한 `commercialCallFunnel`은 저장된 `utm_content` 원값을 서버에서 파싱하므로 랜딩의 표시 로직과 무관하게 office/shop이 정상 분리된다. §1-2 표에 shop 행이 실제로 잡히는 것이 증거다.

남는 실제 손해는 두 가지다.

1. **카피 불일치** — shop 방문자 33명(전체 LPV의 49%)이 "직원이 늘었는데, 사무실은 그대로인가요?"를 봤다.
2. **소재 판정 무효** — D+7(2026-08-29) 체크포인트는 소재별 클릭률로 교체를 판정하는데, shop 소재는 자기 카피로 측정된 적이 없어 그 판정을 적용할 수 없다.

- 수정본: PR [#25](https://github.com/qurkuid/spacebogam-homepage/pull/25) — MERGEABLE / CLEAN, 상업 스위트 **16개 전원 통과** (업종 라우팅 회귀 테스트 5건 신규). 2026-08-23 09:00 KST에 PR head를 격리 워크트리로 받아 재실행해 확인했다.
- 상태: **대표 승인 대기** — 정본 [금지] 조항상 승인 없이 랜딩 배포 불가
- 조치: 해소 시각을 기록하고, 그 이전 shop 구간은 §2 업종축 **카피 판정에서 제외**한다 (트래픽/클릭률 집계는 유효).
