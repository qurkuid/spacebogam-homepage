## 4. 리스크 — 2건 모두 해소

### R1. 업종 라우팅 결함 — 표시 불일치 (**해소**, 2026-08-23 18:55 KST)

**증상(해소 전)**: `assets/commercial-call.js`의 `content.split('__')[0]` 때문에 `utm_content=shop_a` / `shop_b` 가 업종으로 해석되지 않아 **기본값 `office` 문구가 렌더**됐다.

**집계는 오염되지 않았다.** CMP-1336이 신설한 `commercialCallFunnel`은 저장된 `utm_content` 원값을 서버에서 파싱하므로 랜딩 표시 로직과 무관하게 office/shop이 정상 분리된다. §1-2 표에 shop 행이 실제로 잡히는 것이 증거다. 실제 손해는 **카피 불일치**와 그로 인한 **소재 판정 무효** 두 가지였다.

**해소 경로**

| 항목 | 값 |
|---|---|
| PR | [#25](https://github.com/qurkuid/spacebogam-homepage/pull/25) — 상업 스위트 16개 전원 통과 (업종 라우팅 회귀 5건 신규) |
| 머지 커밋 | `df7c37b` |
| 배포 시각 | **2026-08-23 18:55:07 KST** |
| 라이브 재확인 | 2026-08-23 19:12 KST — `spacebogam.kr/assets/commercial-call.js` 직접 수신, `split('__')` 소거 및 `content.split(/[^a-z0-9]+/)` 전 구간 탐색 확인 |

수정 로직은 첫 구간만 보지 않고 구분자로 쪼갠 **모든 구간**에서 업종 토큰을 찾는다. `shop_a`, `shop__a1_condition`, `v5_shop_a` 표기 변형을 모두 흡수한다.

**판정 규칙 (확정)**

- shop 소재의 **카피 성능 판정 구간은 2026-08-23 18:55 KST 이후**로 한정한다.
- 그 이전 shop 트래픽(35 LPV / 4 click)은 **트래픽 정상성·클릭률 집계에는 유효**하나 소재 교체 판정 근거로 쓰지 않는다.
- 결과적으로 D+7(2026-08-29) 소재 판정은 shop 기준 **실질 관측 6일**이다. 이때 shop N이 부족하면 판정을 D+9(2026-08-31)로 이월한다.
